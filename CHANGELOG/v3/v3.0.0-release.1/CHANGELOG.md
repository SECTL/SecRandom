# v3.0.0 - Nonomi (十六夜野宫) release 1

## 🚀 主要更新

- 新增 **Sudo 模式**，验证一次后，设定时间内（默认 60 秒，可在安全设置中调为 10 至 600 秒）抽取、开窗口等操作不用再反复验证；设置页单独计时、关闭即失效，配置 TOTP 仍需重新验证；托盘菜单新增「退出 Sudo 模式」[#283](https://github.com/SECTL/SecRandom/pull/283)
- 新增 **抽取证明链与后台验证**，每份证明都会连成一条链，并自动在后台提交官方验证，断网或重启后继续重试；事后修改证明、删除旧证明、删光重建都能被发现，「抽取验证」页可查看链状态与提交队列
- 新增 **第三方时间戳与名单摘要**，每份证明都会附上时间戳，并记录抽取时所用名单的摘要；抽完再改名单、把中签记录指向别人同样会被发现（只上传摘要，不发送名单和抽取内容）
- 新增 **使用统计上报**，只统计每天的点名、抽奖与启动次数，不带时间、账号或位置信息，在隐私设置中选择「停止」即不再上报；另外每次启动会匿名上报一次版本号与设备标识，仅用于统计各版本使用人数
- 新增 **云备份可选包含抽取证明**，默认关闭；本地证明被删除时，云端备份就是最后一份证据

## 💡 功能优化

- 优化 **在线状态上报**，不再上传 IP 与地区，位置改由服务器按访问地址统计，客户端只上报设备标识与设备类型
- 优化 **文件安全检查**，下载更新、安装插件、导入备份时都会限制文件大小并校验完整性，异常的超大或损坏文件会被直接拒绝，被拒绝的插件包会标记出来
- 优化 **名单名称与文件访问校验**，创建、重命名、导入名单时会拒绝非法字符、相对路径和系统保留名；Android 上安全凭据与语音凭据目录不能再被删除、重命名或移动
- 优化 **密钥与外部地址限制**，语音服务密钥与接口地址绑定，更换地址后需要重新填写；头像下载只允许访问官方地址，且不会带上登录令牌
- 优化 **安全凭据保护**，存放密码与免密 TOTP 种子的文件夹会收紧为只有当前用户可打开，同一台电脑上的其他账户读不到里面的文件（管理员与系统账户仍可访问），已有安装在下次启动时自动收紧；TOTP 种子被改坏时按验证失败处理，不再中断验证流程
- 优化 **设置防篡改校验**，在完整性确认弹窗挂起期间不再执行敏感命令与 secrandom:// 链接

## 🐛 修复问题

- 修复 **主界面导航**，进入设置再返回后，左侧栏高亮仍停留在「设置」而不回到原页面的问题[#268](https://github.com/SECTL/SecRandom/issues/268)
- 修复 **抽取证明上报**，证明导出或上报失败会连带本次抽取失败的问题；现在抽取成功后才会发布证明，发布失败只记录警告并等待重试
- 修复 **备份导入与插件安装**，异常备份包可能覆盖软件配置文件、插件替换失败会留下不完整插件目录的问题；现在失败时都会还原原有文件
- 修复 **账号登录状态**，刷新登录令牌时先把新的访问令牌与刷新令牌一起原子写入磁盘再使用，多个请求同时刷新只会发出一次请求；服务端返回 `invalid_grant` 等终态错误时立即停止重试并清空本地令牌，访问令牌被吊销时不再白白消耗刷新令牌，限流与服务不可用则按提示退避后重试同一次刷新，避免旧令牌被反复提交导致账号被反复退出登录
- 修复 **Android 版本号显示**，平板与手机上的版本号显示为 `v0.0.0.0`，导出的设置与备份也会因版本不符被自己拒绝导回的问题[#289](https://github.com/SECTL/SecRandom/issues/289)
- 修复 **移动端更新检查**，无法识别 `3.0.0-beta.1` 这类预发布版本号，导致始终提示「已是最新」的问题
