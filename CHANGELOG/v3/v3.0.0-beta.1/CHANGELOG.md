# v3.0.0 - Nonomi (十六夜野宫) Beta 1

## 🚀 主要更新

- 新增 **账户系统**，支持登录 思拓创联（SECTL）账户，以便于支持更多功能
- 新增 **云端备份**，登录账号后可将数据备份打包上传到云端、管理云端备份并下载恢复（缺失部分没必要的备份数据），且支持自动备份；多台设备共用同一账号时，备份会带上设备别名，自动备份的保留上限按设备分别计算（云空间不足时仍会删除整个账号最早的备份）
- 新增 **公告**，可在软件内直接查看 思拓创联 官网的所有公告

## 💡 功能优化

- 新增 **设置文件防篡改校验**，开启后在每次保存时记录整份设置文件的指纹，启动时校验该文件是否被程序之外修改；可选择检测到改动时用安全密码确认后才能继续，或按「仅本地 / 本地优先 / 云端优先」的来源顺序自动恢复最近一次备份中的设置文件（恢复前会先另存当前设置文件，恢复成功后自动重启）
- 优化 **安全验证**，验证失败原因直接显示在验证弹窗内，可直接修改后重试，无需关闭弹窗重新打开[#280](https://github.com/SECTL/SecRandom/pull/280)
- 优化 **公平抽取**，将分组、性别在公平抽取中的历史参考占比提升，让未抽取成员的优先顺序符合规律
- 优化 **历史记录**，将科目筛选这个功能补全，需要在打开科目筛选的相关功能后即可使用

## 🐛 修复问题

- 修复 **应用启动**，部分未打齐最新累积补丁的 Windows 10 设备上因 .NET 10 默认启用 CET 影子栈兼容而静默崩溃、双击无反应的问题[#271](https://github.com/SECTL/SecRandom/issues/271)
- 修复 **密码与 API 密钥输入框**，未禁用输入法导致中文输入法可能意外输入、引发格式错误的问题[#281](https://github.com/SECTL/SecRandom/pull/281)
- 修复 **备份恢复**，预发布版本号（如 v3.0.0-alpha.2）被误判为非 v3 归档，导致无法恢复同版本备份的问题
- 修复 **插件市场**，最低宿主版本校验被静默跳过，导致要求更高宿主版本的插件仍被判定为兼容的问题
- 修复 **安全验证**，「任意验证方式」模式下只填写 TOTP 验证码时按钮可提交却必然失败，且会被计为一次密码错误；现在 TOTP 可在该模式下单独完成验证，升级后首次需先用主密码验证一次以启用免密副本[#275](https://github.com/SECTL/SecRandom/issues/275)
- 修复 **课程联动**，ClassIsland 数据源在放学后与第二天开课前会被判为「时间状态未确认」而直接放行，导致「限制非上课时段操作」在这些时段失效、「课后禁用延迟」始终不生效的问题；现在放学、开课前与时间表空档都按已确认的非上课时段处理，与 CSES 数据源保持一致（启用「下课隐藏悬浮窗」时这些时段同样隐藏）[#278](https://github.com/SECTL/SecRandom/issues/278)
- 修复 **课程联动**，ClassIsland 数据源的倒计时每次刷新都会让联动状态被判定为变化，刷新因此陷入自激循环，使 SecRandom 与 ClassIsland 各占用约 50% CPU 并拖慢系统的问题；现在联动与通知共用同一条 IPC 连接，只在状态语义变化时通知，连接失败时按退避重试[#274](https://github.com/SECTL/SecRandom/issues/274)
