# v3.0.1 - Nonomi (十六夜野宫)

## 🚀 主要更新

- 新增 **导入 Excel/CSV 名单时可自选导入区域**，不再固定把第一行当成表头：可以选择工作表、指定表头所在的行，也可以直接点表格里的某一行把它设为表头，并限定只导入哪几行数据；表格里的行号与 Excel 中看到的完全一致，名单不在第一个工作表、表格开头有标题行或空行、结尾有合计行时都能正常导入
- 新增 **低配模式**（设置 → 常规 → 基础设置 → 性能）：关闭页面与弹窗动画、降低图片缩放质量，并停用主窗口与设置窗口的半透明背景；不影响抽取动画与悬浮窗，需重启生效
- 新增 **Sudo 模式总开关与说明卡片**（设置 → 常规 → 安全）：Sudo 模式此前固定开启、无法关闭，现在可以一键开关，并在同一张可展开的卡片里看到「操作范围」「设置窗口范围」「始终需要重新验证的操作」三段说明，不再需要靠猜
- 新增 **移动端账号登录**：Android 与 iOS 现在可以直接在手机上登录 SECTL 账号（设置 → 常规 → 备份 → 云端备份），授权页在系统浏览器中打开，登录后令牌保存在应用私有目录；桌面端继续使用原有的本机回调方式，登录与令牌刷新流程不变
- 新增 **移动端云端备份**：手机上可以查看云端备份列表与空间占用、上传备份、下载后恢复、删除备份以及清理未完成的备份，云端自动备份也与桌面端一致；恢复完成后手机端直接刷新界面，桌面端仍按原流程提示重启

## 💡 功能优化

- 优化 **抽取动画的图片解码**：结果里的学生/奖品照片此前每一帧都重新从磁盘解码，现在缓存复用，一轮抽取里同一张照片只读一次
- 优化 **计时器空闲时不再占用 CPU**：此前打开过一次计时器后，即使窗口已关闭仍会每秒刷新 30 次界面；现在只在窗口可见且确实在计时时才刷新
- 优化 **Sudo 模式的时长与边界**：有效时长默认值由 60 秒调整为 20 秒，仍可在 10 至 600 秒之间调整；设置窗口的免验证此前不按时长计算，验证一次会一直有效到关闭窗口，现在改为同样按有效时长计时，关闭设置窗口依旧立即失效；关闭安全保护、取消验证方式、关闭防篡改校验或延长该时长等放宽防护的改动，始终需要重新输入安全密码，上课时间的例外验证也不再被 Sudo 覆盖；托盘菜单的「退出 Sudo 模式」会同时结束全局与设置窗口的免验证状态
- 优化 **防篡改自动恢复的备份选择**：开启「篡改处理方式 → 自动恢复」并使用云端备份时，只用本机上传的云端备份并按时间从新到旧尝试，其他设备上传的备份一律不再使用；本机没有任何可用备份时就保持当前设置文件不动，回退到安全密码确认
- 优化 **账号登录与令牌刷新不再上传 IP**：此前登录和刷新令牌前，客户端会先向第三方 IP 查询接口获取本机公网地址，再随请求一起上传；现在客户端不再访问任何 IP 查询服务，请求里也不再带 IP，地址由服务器按访问来源统计，客户端只上报设备标识
- 优化 **云端备份改为按原样上传，恢复不再需要密码**：此前云端备份会先用密码加密再上传，忘记密码等于备份永久打不开；现在归档按原样上传，凭账号就能在任何已登录设备上恢复（平台侧因此可以看到备份内容，这是为可恢复性接受的取舍）；旧版加密备份仍会显示在列表里并标记「旧版加密，无法恢复」，可以删除但无法打开
- 优化 **移动端登录的容错**：登录期间如果应用被系统回收，再次打开时会用此前记录的授权信息直接完成登录，不必重新登录一次；授权页被关闭、用户取消授权或长时间无响应时会立刻给出明确提示，不再一直停在「登录中」
- 优化 **移动端导入设置或备份后的提示**：手机导入后不再出现「未能移除开机启动注册」这类只属于桌面端的提示

## 🐛 修复问题

- 修复 **导入备份可能绕过安全验证**：安全保护开关本身随 `settings.json` 一起被导入，此前一份构造过的设置导出或全量备份可以直接把安全保护关掉；现在导入或恢复会放宽防护的配置前必须重新输入安全密码，未通过验证会在写入任何数据之前中止整次导入
- 修复 **在「更多设置」中开关抽奖时主界面报错**，开关本身能正常生效，但主窗口会弹出崩溃提示；打开过设置后再关闭抽奖，左侧导航栏的高亮也可能一起丢失；现在切换抽奖只会显示或隐藏抽奖入口，不再重建导航栏
- 修复 **移动端恢复备份后界面不刷新**：手机上恢复本地或云端备份后，此前只提示恢复成功，界面与运行时仍是旧数据（移动端无法像桌面端那样自行重启进程）；现在会重建移动端界面并展示恢复后的配置
- 修复 **云备份的设备别名在手机上全部相同**：手机此前用主机名做别名，而 Android 与 iOS 的主机名都是 `localhost`，同一账号下的多台手机会被当成同一台设备，云端列表分不清是哪台机器上传的，各自的保留数量也会互相顶掉；现在改用设备机型与设备名，仍可在「设备别名」中自行填写
