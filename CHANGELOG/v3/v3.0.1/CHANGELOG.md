# v3.0.1 - Nonomi (十六夜野宫)

## 🚀 主要更新

- 新增 **导入 Excel/CSV 名单时可自选导入区域**，不再固定把第一行当成表头：可以选择工作表、指定表头所在的行，也可以直接点表格里的某一行把它设为表头，并限定只导入哪几行数据；表格里的行号与 Excel 中看到的完全一致，名单不在第一个工作表、表格开头有标题行或空行、结尾有合计行时都能正常导入
- 新增 **低配模式**（设置 → 常规 → 基础设置 → 性能）：关闭页面与弹窗动画、降低图片缩放质量，并停用主窗口与设置窗口的半透明背景；不影响抽取动画与悬浮窗，需重启生效
- 新增 **Sudo 模式总开关与说明卡片**（设置 → 常规 → 安全）：Sudo 模式此前固定开启、无法关闭，现在可以一键开关，并在同一张可展开的卡片里看到「操作范围」「设置窗口范围」「始终需要重新验证的操作」三段说明，不再需要靠猜
- 新增 **云端备份加密**（设置 → 常规 → 备份 → 云端备份）：备份会先在本机用 AES-256-GCM 加密，再分片上传，云端只保存无法读取的密文。账号云服务、后端，乃至任何被替换成自己部署的端点，都拿不到名单、历史与设置里的实际内容。**默认关闭**，可在该页面开启，开启时会先要求设置加密口令
- 新增 **云端备份加密口令**：口令通过 Argon2id 派生加密密钥，派生结果只缓存在本机 `data/config/security` 受限目录里，不进入设置、备份或云端，因此日常的自动备份与恢复不需要反复输入口令；在另一台设备上输入同一个口令，就能解开同一账号下用该口令上传的加密备份。加密功能上线前上传的旧备份不受影响，仍可正常下载恢复
- 云端备份列表新增 **加密状态列**：已加密的备份会标注「已加密」，旧备份标注「明文」，一眼即可分辨

## 💡 功能优化

- 优化 **抽取动画的图片解码**：结果里的学生/奖品照片此前每一帧都重新从磁盘解码，现在缓存复用，一轮抽取里同一张照片只读一次
- 优化 **计时器空闲时不再占用 CPU**：此前打开过一次计时器后，即使窗口已关闭仍会每秒刷新 30 次界面；现在只在窗口可见且确实在计时时才刷新
- 优化 **Sudo 模式的时长与边界**：有效时长默认值由 60 秒调整为 20 秒，仍可在 10 至 600 秒之间调整；设置窗口的免验证此前不按时长计算，验证一次会一直有效到关闭窗口，现在改为同样按有效时长计时，关闭设置窗口依旧立即失效；关闭安全保护、取消验证方式、关闭防篡改校验或延长该时长等放宽防护的改动，始终需要重新输入安全密码，上课时间的例外验证也不再被 Sudo 覆盖；托盘菜单的「退出 Sudo 模式」会同时结束全局与设置窗口的免验证状态
- 优化 **加密与上传的关系**：开启加密但没有设置口令时，开启动作会先要求设置口令，取消则不会把开关留在开启状态；自动备份在没有口令时会跳过本次并写入日志，不会悄悄退回明文上传；关闭加密时会明确提示之后的备份将以明文上传
- 优化 **误输加密口令的处理**：恢复加密备份时输错口令会直接提示并允许重新输入，连续输错才结束本次恢复；在账号里已有加密备份的设备上设置口令时，会直接校验口令是否与云端一致，输入错误会当场拒绝，不会留下两把互不相通的密钥
- 优化 **防篡改自动恢复的备份选择**：开启「篡改处理方式 → 自动恢复」并使用云端备份时，此前可能因为另一台设备上传的备份更新而拿它的设置来覆盖本机；现在先在本机上传的云端备份里按时间从新到旧找，本机确实没有可用备份时才退回其他设备，并且会在日志里写明用了别的设备的备份

## 🐛 修复问题

- 修复 **导入备份可能绕过安全验证**：安全保护开关本身随 `settings.json` 一起被导入，此前一份构造过的设置导出或全量备份可以直接把安全保护关掉；现在导入或恢复会放宽防护的配置前必须重新输入安全密码，未通过验证会在写入任何数据之前中止整次导入
- 修复 **在「更多设置」中开关抽奖时主界面报错**，开关本身能正常生效，但主窗口会弹出崩溃提示；打开过设置后再关闭抽奖，左侧导航栏的高亮也可能一起丢失；现在切换抽奖只会显示或隐藏抽奖入口，不再重建导航栏
