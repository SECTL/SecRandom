# v3.0.1 - Nonomi (十六夜野宫)

## 🚀 主要更新

- 新增 **导入 Excel/CSV 名单时可自选导入区域**：支持用户选择工作表、表头、导入范围
- 新增 **低配模式**：关闭页面与弹窗动画、降低图片缩放质量，并停用主窗口与设置窗口的半透明背景；不影响抽取动画与悬浮窗，需重启生效
- 新增 **Sudo 模式**：Sudo 模式增加是否启用开关，且带有解释小卡片
- 新增 **移动端账号登录**：Android 与 iOS 现在可以直接在手机上登录 思拓创联 账号
- 新增 **移动端云端备份**：手机上可以查看云端备份列表与空间占用、上传备份、下载后恢复、删除备份以及清理未完成的备份，云端自动备份也与桌面端一致，恢复完成后手机端直接刷新界面，桌面端仍按原流程提示重启
- 新增 **OOBE**：集控设置纳入OOBE流程
- 新增 **集控**：可在移动端控制桌面端，也可在 Web 管理加入集控网络的所有客户端，并且支持用户权限管理；桌面端现在可以作为被集控节点接入，本机集控关闭后任何远程命令都不会执行
- 新增 **计时器设置**：支持设置倒计时、秒表、时钟是否自动经过设置的时间变为小窗

## 💡 功能优化

- 优化 **抽取动画的图片**：结果的图片增加缓存，以减少占用
- 优化 **计时器**：空闲时不再占用 CPU
- 优化 **Sudo 模式的时长与边界**：有效时长默认值由 60 秒调整为 20 秒，仍可在 10 至 600 秒之间调整；设置窗口的免验证此前不按时长计算，验证一次会一直有效到关闭窗口，现在改为同样按有效时长计时，关闭设置窗口依旧立即失效；关闭安全保护、取消验证方式、关闭防篡改校验或延长该时长等放宽防护的改动，始终需要重新输入安全密码，上课时间的例外验证也不再被 Sudo 覆盖；托盘菜单的「退出 Sudo 模式」会同时结束全局与设置窗口的免验证状态
- 优化 **防篡改自动恢复的备份选择**：开启「篡改处理方式 → 自动恢复」并使用云端备份时，只用本机上传的云端备份并按时间从新到旧尝试，其他设备上传的备份一律不再使用

## 🐛 修复问题

- 修复 **导入备份**：未通过验证会在写入任何数据之前中止整次导入
- 修复 **在「更多设置」中开关抽奖时主界面报错**：切换抽奖只会显示或隐藏抽奖入口，不再重建导航栏
- 修复 **移动端恢复备份后界面不刷新**：重建移动端界面并展示恢复后的配置
