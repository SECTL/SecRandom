# v3.1.5 - Nonomi (十六夜野宫)

## 🚀 主要更新

- 新增 **插件扩展能力（宿主 API 3.1.5）**：插件可以自行呈现抽签结果、插入界面、叠加内容、调整配色、使用私有存储、查询名单与奖池、弹出通知与对话框、调度界面线程、提供多语言文案、订阅宿主事件、上报运行诊断，并在退出时执行收尾清理
- 新增 **集控**：可接入自部署集控啦！

## 💡 功能优化

- 优化 **抽取设置的「动画样式」**：四个抽取设置页统一改用新的动画样式选择器，内置动画与插件动画在同一个下拉里选择
- 优化 **选中插件动画后插件失效的处理**：插件被卸载或禁用时，原先选中的插件动画会在启动时自动恢复为宿主内置动画，不会再出现空白的「动画样式」
- 优化 **插件呈现结果的文案**：宿主会把按显示格式拼好的结果文本一并交给插件，插件牌面上的文字与内置结果卡完全一致
- 优化 **插件多语言文案**：切换界面语言后插件注册的文案会立刻刷新，不需要重启
- 优化 **插件的窗口与弹层**：同一标识的插件窗口会被复用；宿主没有叠加层时自动回落为独立窗口
- 优化 **插件出错时的抽签稳定性**：插件的候选项过滤、结果后处理与结果呈现即使出错也只跳过它自己那一步并记录日志，抽签本身照常完成

## 🐛 修复问题

- 修复 **导出数据时日志被占用**：正在写入的当前日志现在也能正常导出，导出全部数据不再因此失败，诊断数据里也不会再缺少日志
