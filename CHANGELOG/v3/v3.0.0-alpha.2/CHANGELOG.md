# v3.0.0 - Nonomi (十六夜野宫) alpha 2

## 🚀 主要更新

- 新增 **插件系统**，支持本地安装插件，从插件市场下载插件
- 新增 **Omni TTS**，支持调用 Omni TTS 接口，如 OpenAI、Xiaomi MiMo，且支持 Mimo 的音色克隆
- 新增 **计时器**，支持倒计时、秒表、时钟三大板块，且支持小窗

## 💡 功能优化

- 优化 **设置头像**，支持选择文件夹，自动批量设置成员/奖品的头像
- 优化 **语音播报**，支持批量生成音频缓存、清空缓存

## 🐛 修复问题

- 修复 **关于页面** 中，Banner 无法显示的问题
- 修复 **应用生命周期** 中，阻塞系统关闭的问题
- 修复 **浮窗** 中，「抽」的本地化缺失的问题
- 修复 **更新日志** 中，高速下载链接生成错误的问题
- 修复 **闪抽** 中，可能出现闪抽触发失败的问题
- 修复 **点名/闪抽** 中，可能出现点名名单使用错误的问题
