# v3.0.0 - Nonomi (十六夜野宫) Beta 2

## 🚀 主要更新

- 新增 **Sudo 模式**，验证通过后可在设定时长内跳过抽取、窗口等敏感操作的重复验证（默认 60 秒，可在安全设置中调整为 10 至 600 秒）；设置页面有独立有效期，关闭设置窗口即失效，配置 TOTP 仍始终需要重新验证；托盘菜单新增「退出 Sudo 模式」，只清除全局免验证状态[#283](https://github.com/SECTL/SecRandom/pull/283)
- 新增 **证明链与提交队列**，抽取证明按追加式哈希链保存，普通模式的证明会立即保存并在后台提交服务端重放验证，失败自动按退避重试、断网或重启后继续提交；事后修改、删除旧证明、删光重建以及提交期间证明被改动都能被发现（服务端会记住每台设备见过的链头），「抽取验证」页可查看链的缺口、断链、被改动、超出链头、未落盘与过期，以及队列的待提交、失败、冲突与告警计数
- 新增 **时间戳与名单摘要**，每份证明都会申请 RFC 3161 第三方时间戳，并承诺抽取时所用名单的「记录 ID → 姓名/学号/组别」映射摘要，抽取之后再改名单、把中签记录指向别人同样会被发现；两者都只发送摘要，不发送名单或抽取内容
- 新增 **使用统计上报**，统计点名、抽奖与启动次数，上报字段与每日/每周/每月/总计四个周期口径均与 v2 一致；在隐私设置中选择「停止」后不再上报
- 新增 **云备份可选包含抽取证明**，默认关闭，因为本地证明被删除后云端才是最后一份证据

## 💡 功能优化

- 优化 **在线状态上报**，不再由客户端上报公网 IP 与粗略地区（也不再请求第三方 IP 查询服务），位置改由服务端按访问地址统计，客户端只上报设备标识与设备类型
- 优化 **归档与插件包校验**，为更新下载、插件市场索引与插件包引入压缩/解压/条目/清单大小预算，边读边计数以阻止解压炸弹与超大响应，被拒绝的插件包会标记为 .rejected；云端备份的清单、分片与整个归档增加长度上限、SHA-256 一致性与溢出保护
- 优化 **路径与文件名校验**，名单的创建、重命名、导入与切换会拒绝相对路径、Windows 保留设备名与非法字符，Android 文件访问统一按 canonical 路径判断可访问性与可变性，安全凭据与语音凭据目录不可删除、重命名或移动
- 优化 **凭据与外部地址限制**，OmniTTS 密钥与提供商及其规范化接口地址绑定，更换接口地址需要重新填写，旧版只按提供商保存的密钥不再自动信任；头像下载仅允许固定的 SECTL HTTPS 地址，且不会携带登录令牌
- 优化 **设置文件完整性校验**，在完整性确认弹窗挂起期间阻止执行敏感命令与 secrandom:// 协议调用

## 🐛 修复问题

- 修复 **主界面导航**，在 Windows 与平板端从主界面进入设置（再返回）后，左侧栏高亮仍停留在「设置」而不回到原页面的问题；设置入口不再参与左侧栏选中[#268](https://github.com/SECTL/SecRandom/issues/268)
- 修复 **抽取证明发布**，证明导出或上报失败会连带本次抽取失败的问题；现在抽取提交成功后再发布证明，发布失败只记录警告并保持待发布状态
- 修复 **备份导入与插件安装**，异常的归档可能通过子路径覆盖 config/settings.json、config/device-uuid.json 等固定配置文件、插件替换失败会留下不完整插件目录的问题；现在两者失败时都会恢复原有文件
