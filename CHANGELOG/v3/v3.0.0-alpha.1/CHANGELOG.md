# v3.0 - Nonomi (十六夜野宫) alpha 1

## 🚀 主要更新

- 完成技术栈**重构**，从 **Python/PySide6/QFluentWidgets** 迁移至 **C#/.NET/Avalonia/FluentAvalonia**，提升跨平台能力、启动稳定性与长期可维护性
- 新增 **可验证抽取证明**，支持本地可复现证明、公开校验数据和正式在线见证流程，便于复核抽取结果
- 新增 **导出、导入名单方式**，增加二维码、会话码导出名单至其它设备
- 新增 **崩溃恢复**，能够在崩溃后显示报错信息，且能自动重启软件
- 新增 **概览**，方便用户查看 **点名**、**抽奖** 的各个名单概览信息
- 新增 **抽取动画**，v2的孤寡动画，生了两个动画，变成了一家三口
- 新增 **抽奖开关**，可控制是否开启抽奖功能
- 新增 **语音播报独立设置**，可配置每个抽取方式下的语音播报设置
- 新增 **音乐库**，可在独立页面管理音乐文件
- 新增 **特定目录打开**，可在软件内打开日志、数据、应用目录
- 新增 **反馈**，可在软件内直接通过 Sentry 进行提交 Bug反馈、新功能
- 新增 **Debug页面**，更好测试软件的部分功能
- 新增 **标题栏版本号**，便于清楚知道当前版本号

## 💡 功能优化

- 优化 **公平抽取**，大大提高了**公平性**，内涵算法增多
- 优化 **启动速度**，启动速度相比v2提升巨大
- 优化 **个性化**，字体设置直观，可查看显示效果
- 优化 **更多设置**，化繁为简，整齐收纳
- 优化 **名单管理**，界面直观，使用便利
- 优化 **调整数量**，优化抽取数量调整操作，长按时增速随按压时间动态加快
- 优化 **界面美观度**，界面整体美观度提升，字体、图标不模糊
- 优化 **主界面**，大字号显示，查看不累眼
- 优化 **头像显示**，头像显示采用圆角，舒适大方
- 优化 **剩余名单页面**，布局调整，更加美观
- 优化 **设置搜索**，优化候选结果的显示
