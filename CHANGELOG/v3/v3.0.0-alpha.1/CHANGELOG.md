# v3.0 - Nonomi (十六夜野宫) alpha 1

## 🚀 主要更新

- 完成技术栈重构，从 Python/PySide6/QFluentWidgets 迁移至 C#/.NET/Avalonia/FluentAvalonia，提升跨平台能力、启动稳定性与长期可维护性
- 新增 **点名、闪抽、抽奖** 三类抽取流程，支持独立配置、独立临时记录和更统一的动画与结果展示
- 新增 **公平抽取引擎**，支持频率、分组、性别、时间、平均值差值保护等因素，并支持抽取历史平衡
- 新增 **可验证抽取证明**，支持本地可复现证明、公开校验数据和正式在线见证流程，便于复核抽取结果
- 新增 **安全设置与授权服务**，支持密码、TOTP、USB 等验证因素及受保护操作控制
- 新增 **首启 OOBE 向导**，整合语言选择、名单/奖品导入、隐私政策、GPLv3 与可验证抽取说明确认
- 新增 **课程联动**，支持 CSES 与 ClassIsland 数据源，并在确认课程限制时控制抽取、重置和浮窗行为
- 新增 **ClassIsland v2 通知集成**，并统一内置结果窗口与外部通知失败时的回退策略
- 新增 **音乐库与抽取播报设置**，支持按抽取类型选择过程音乐、结果音乐和附加设置
- 新增 **插件运行框架**，支持插件注册页面、受限抽取调用和独立日志分类

## 💡 功能优化

- 优化 **主界面与导航**，采用更清晰的侧栏布局，重构悬浮窗、快速抽取窗口和设置页面交互
- 优化 **设置配置**，按功能分类拆分并保留旧版配置兼容迁移；备份、恢复和导入改用带版本校验的 v3 数据格式
- 优化 **名单与奖品管理**，统一导入、预览、字段映射、重复项处理和稳定记录身份，显示编号不再承担内部唯一身份
- 优化 **公平性与临时记录**，点名和快速抽取共享学生临时记录，抽奖使用独立奖品记录，避免不同抽取模式互相污染
- 优化 **更新分发流程**，支持跨平台安装包与便携包、Launcher 版本切换、更新包哈希校验和 Ed25519 签名清单
- 优化 **数据路径与备份**，运行数据统一保存在程序目录的 `data/` 下，设备标识与普通设置分离，避免备份或迁移时误覆盖身份
- 优化 **语言与字体体验**，默认简体中文，支持运行时语言切换、系统字体和字体搜索
- 优化 **桌面集成**，支持跨平台自启动、`secrandom://` 协议激活、Windows UIAccess 置顶和更稳定的单实例 IPC
- 优化 **语音与动画**，重构语音提供器、统一三类抽取的动画样式，并改善取消、停止、播报和结果展示状态恢复

## 🐛 修复问题

- 修复 **公平抽取权重** 未正确参与最终抽取、屏蔽期仍可能重复抽取、历史匹配不一致和保护池选择不准确等问题
- 修复 **点名、闪抽、抽奖** 读取错误抽取配置、临时记录串用和抽取完成后状态未完整恢复的问题
- 修复 **配置与设置持久化**，补齐子项保存、旧版配置迁移、运行时路径和数据备份恢复边界
- 修复 **语言与本地化** 资源初始化、运行时切换、设置页面导航和多语言回退问题
- 修复 **浮窗与主窗口** 在 Linux、深色主题、UIAccess 置顶、贴边收纳和自动显示场景下的交互问题
- 修复 **更新流程** 中的版本读取、更新源回退、404 提示、文件识别、下载校验和安装衔接问题
- 修复 **单实例与 IPC** 超时、协议解析、外部启动和受保护命令路由问题
- 修复 **课程联动与平台连接** 在连接丢失、数据缺失或状态未知时错误限制正常使用的问题
- 修复 **语音、音乐与通知** 播放停止、失败回退、ClassIsland 连接和内置结果窗口状态问题

## 🔧 其它变更

- 移除摄像头、人脸检测相关代码，聚焦稳定的名单、奖品与公平抽取流程
- 统一项目的 Core、Shared、App 和 Desktop 分层
- 发布版本改用 v3 版本号、更新清单和发布签名流程
