# v3.2.0 - Beta 1 - Nonomi (十六夜野宫)

## 🚀 主要更新

- 新增 **浮窗支持屏幕两侧**，开启后可以更方便的让你进行快速操作
- 新增 **历史记录组**，开启后可以在点名/抽奖页面设置接下来抽取的历史记录存放在哪个历史记录组内。如果使用公平抽取模式，将会影响后续的公平性
- 新增 **随机数模式**，可在点名/抽奖的名单中选择随机数给你，将可以直接进行随机数的抽取。随机数的默认值可在设置内调整
- 新增 **简洁模式**，主要是部分用户想要一个最简单的抽取样式，你如果觉得你使用 SecRandom 只用了点名名单和闪抽，那你可以使用这个功能，当然没有多余的娱乐功能了
- 新增 **全屏通知渠道**，可以全屏显示结果，并且有动画样式可以选择，而且可以配置背景图片，能让抽取更有意思。“打字机”动画支持文案库，你也可以手动添加，或者发送内置提示词给AI生成后进行粘贴导入
- 新增 **浮窗通知设置页面**，可以配置浮窗的一些功能，以及样式
- 新增 **浮窗组件可自定义**，可以自定义配置浮窗内的组件，并且支持打开其他文件/URL，支持自定义名称、图标
- 新增 **浮窗收纳样式可自定义**，为了一些用户觉得“抽”和单一的图标觉得标识不明显，可以自行配置该样式
- 新增 **课程联动严格限制功能**，可以防止IPC断联时依旧保持安全锁定状态，默认关闭
- 新增 **浮窗通知自适应前景色**，支持自动根据背景调整浮窗通知的外观，大大提升了可读性。该功能默认开启，如果开启低配模式将会自动关闭
- 新增 **更新源**，支持了思拓创联官方服务器分发源
- 新增 **关于-本机信息**，可在关于页面查看本机的一些信息
- 新增 **关于-抽取算法版本号**，支持在关于页面查看抽取算法的版本号
- 新增 **浮窗支持无焦点**，为防止点击浮窗时出现焦点切换，导致影响PPT的放映，支持开启，如果在部分系统环境下有Bug可以自行关闭
- 新增 **编排模式**，可以在部分场景（eg:公开课、演示等）进行一个固定顺序/权重修改/排除一些成员/延后一些成员滞后抽取，对部分不需要随机/公平抽取的场景进行支持
- 新增 **闪抽长按支持抽多人**，默认开启，长按闪抽可出现数量显示组件在左侧/右侧，上下拖动后松手即可快速抽取多人（1~5人）
- 新增 **公平抽取设置值**，可选择公平抽取算法倾向，分为 **均匀优先（默认）、随机优先**，修改为随机优先后可以有细微感知抽取的随机性会稍强，如果担心被台下的人骂，我建议还是均匀优先好一点
- 新增 **浮窗通知关闭倒计时样式**，默认设置为“四周进度”，汇总浮窗通知的四周显示关闭倒计时，并且可以自定义颜色，默认为蓝红渐变
- 新增 **数据储存**，可以手动修改数据默认保存的位置，并且支持一键迁移

## 💡 功能优化

- 优化 **名单管理增减成员/奖品体验**，单独添加/减少一位成员序号重叠/缺失会自动询问用户该执行推后/不动行为
- 优化 **登录后授权的页面**，变得……好看了
- 优化 **IPC接口**，拓展了部分接口的功能，并且优化了IPC部分管道名称
- 优化 **部分名称优化**，将“SecRandom 文档站”改为“SecRandom 官网”、“SecRandom 内置通知”改为“SecRandom 浮窗通知”
- 优化 **集控**，支持思拓创联官方集控API接口，旧的集控将不可使用，桌面端支持地点码+配对码/登录账号的形式进行连接集控；移动端登录账号后即可远程抽取对应设备上的特定名单
- 优化 **历史记录**，将每种抽取模式的默认历史分开计算，避免影响公平抽取的计算
- 优化 **CPU占用&RAM占用**，这一次只能说是降低了部分，下次再接再厉
- 优化 **浮窗点击**，小修小补了浮窗的点击准确性

## 🐛 修复问题

- 修复 **便携版开机启动项指向版本文件夹**，便携包的自启动与 `secrandom://` 协议注册现在指向包根目录的 `SecRandomLauncher`，而不是 `app-*` 版本目录里的 `SecRandom.Desktop.exe`
- 修复 **Edge TTS 生成报错**，更新库版本支持了v2版本
- 修复 **默认数据目录存放位置**，修复在便携模式下和安装版本下的数据目录的默认存放位置不标准的情况
